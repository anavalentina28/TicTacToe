# TicTacToe

Aplicación web del juego Tres en Raya (TicTacToe), desarrollada en Java EE 
utilizando Servlets, JSP y JSTL. Proyecto realizado para la asignatura Servidores - Universidad del Cauca.

## Tecnologías
- Java EE (Servlets, JSP, JSTL)
- Apache Tomcat 9 / WildFly
- Eclipse IDE

## Funcionalidad
- El usuario puede elegir quién inicia la partida (usuario o computador).
- El computador juega automáticamente sus turnos de forma aleatoria.
- Se detecta ganador por filas, columnas o diagonales.
